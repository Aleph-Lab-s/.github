# Aleph Labs Code of Conduct

Aleph Labs is an institution built around invention, engineering rigor, and responsible technology development.

Participants are expected to:

- treat others with respect
- debate ideas rather than attack people
- communicate clearly and professionally
- disclose uncertainty honestly
- challenge technical assumptions constructively
- protect confidential and security-sensitive information
- avoid harassment, discrimination, intimidation, and personal attacks

Technical disagreement is welcome.

Unprofessional conduct is not.

Maintainers may moderate discussions, issues, pull requests, and other project spaces when necessary to preserve a productive engineering environment.
