# Support

Use the appropriate channel for the type of request.

## Engineering questions

Use repository Discussions when enabled.

## Bugs

Use GitHub Issues when the problem is appropriately scoped for issue tracking.

## Security

Do not use public Issues or Discussions for security vulnerabilities.

Follow `SECURITY.md`.

## Commercial or partnership requests

Use the official Aleph Labs contact channel.

## Governance

Questions about institutional policy or repository governance belong in the appropriate internal governance channel.
