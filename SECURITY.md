# Security Policy

Security is a first-class institutional responsibility at Aleph Labs.

## Reporting a vulnerability

Do not disclose security vulnerabilities through public issues, pull requests, or public discussions.

Use the repository's private security reporting mechanism where available.

If a repository does not yet expose an appropriate private reporting mechanism, contact the authorized Aleph Labs security maintainers privately.

## Do not include

Do not publicly disclose:

- credentials
- private keys
- tokens
- customer information
- sensitive infrastructure information
- exploitable vulnerability details

## Security principle

Security controls must fail closed where failure could create unauthorized authority, access, execution, or side effects.

Security-sensitive changes may require additional review and validation.

## Scope

This policy applies to Aleph Labs repositories and engineering systems unless a repository publishes stricter requirements.
