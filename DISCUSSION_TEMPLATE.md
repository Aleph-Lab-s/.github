# Aleph Labs Discussions

Discussions are for engineering conversation, research, architecture, questions, ideas, and institutional communication.

## Use Discussions for

- technical questions
- architecture conversation
- research ideas
- engineering proposals
- lessons learned
- announcements
- non-urgent community conversation

## Use Issues for

- specific bugs
- scoped implementation work
- tracked engineering tasks
- actionable defects

## Use private channels for

- security vulnerabilities
- confidential information
- customer-sensitive information
- credentials or secrets
- personnel matters

## Discussion principle

Discussions should improve the institution's collective understanding.

When a discussion becomes an actionable engineering task, move it into the appropriate repository issue or planning mechanism.
